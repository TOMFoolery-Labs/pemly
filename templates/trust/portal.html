Installation Instructions

  1. Download the .cer certificate file above
  2. Go to Settings app
  3. Tap Profile Downloaded (appears near top)
  4. Tap Install in the top right, enter your passcode
  5. Tap Install again to confirm
  6. Go to Settings > General > About > Certificate Trust Settings
  7. Enable full trust for {{ ca.common_name }}

Important: You must enable trust in Certificate Trust Settings for the certificate to work with Safari and other apps.

  1. Download the .cer certificate file above
  2. Go to Settings > Security (or Security & Privacy)
  3. Tap Encryption & credentials (or Advanced > Encryption)
  4. Tap Install a certificate > CA certificate
  5. Select the downloaded certificate file
  6. Name the certificate (e.g., "{{ ca.name }}")
  7. Tap OK to install

Note: The exact steps may vary depending on your Android version and device manufacturer. Look for "Install certificates" in your Settings search.

  1. Download the .cer or .crt certificate file
  2. Double-click the downloaded file to open Keychain Access
  3. Select System keychain (for all users) or login (for current user)
  4. Enter your password when prompted
  5. Find the certificate, double-click it
  6. Expand Trust section
  7. Set "When using this certificate" to Always Trust
  8. Close the window and enter your password to confirm
  1. Download the .cer certificate file
  2. Double-click the downloaded file
  3. Click Install Certificate...
  4. Select Local Machine and click Next
  5. Select Place all certificates in the following store
  6. Click Browse and select Trusted Root Certification Authorities
  7. Click Next, then Finish
  8. Click Yes when prompted about security

Tip: You may need Administrator privileges. Right-click the file and select "Run as administrator" if needed.

  1. Download the .crt (PEM) certificate file
  2. Debian/Ubuntu: 
    sudo cp {{ ca.name|slugify }}.crt /usr/local/share/ca-certificates/
sudo update-ca-certificates
  3. RHEL/Fedora/CentOS: 
    sudo cp {{ ca.name|slugify }}.crt /etc/pki/ca-trust/source/anchors/
sudo update-ca-trust extract

Note: For Firefox, you may need to import the certificate separately via Preferences > Privacy & Security > Certificates.
