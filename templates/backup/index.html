ENCRYPTION_KEY Required for Restore

Private keys in backups are encrypted using your server's ENCRYPTION_KEY environment variable. The backup password (optional) provides an additional layer of protection for the backup file itself, but you must have the original ENCRYPTION_KEY configured to use any restored private keys. Store your ENCRYPTION_KEY securely and separately from your backups.
