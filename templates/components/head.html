The title and extra_css blocks stay in those shells: a block inside an included template cannot be overridden by the page that extends the shell. Alpine is served from our own static files, not a CDN. A third-party script tag executes with full authority inside an authenticated session on a certificate authority, and `3.x.x` floats - a hijacked or simply changed response would run here. Serving it locally also keeps the UI working in the air-gapped deployment, which has no outbound access at all.
